- Work only inside a new page named exactly `EXPLORAÇÃO — #<issue> — <assunto>`. Do not delete the exploration page — the orchestrator deletes it only after confirming the promotion. Return the version id, and an old → new node map for every promoted frame, component and variable.
- Return: the page node id and a direct link to it and to each option frame (`https://www.figma.com/design/90oyvXHxxBQAvr1netov7S/?node-id=<id>` with `:` → `-`), a one-paragraph summary per option, and anything you could not resolve.
