# Athlete-specific learning R4

population prior + grounded athlete history + comparable recent responses + current context → ordinal option preference.

Repeated comparable association may change which already-admissible arrangement is preferred. It cannot create a new physiological law, a hard prohibition or an unreviewed dose. No fixed universal observation-count threshold is asserted. Recency is used only when chronology is known; undated histories remain undated.

Retain population prior under noisy or mixed evidence; consistent comparable observations can support a reversible soft preference. Contradiction or context change weakens it; no irreversible global athlete rule.

The reference uses pure evidence/model proposals, with provenance and visible uncertainty. This is not production persistent learning, empirical calibration or proof of causal interference. New single/noisy evidence retains the prior. General session placement, recovery assumptions and progression aggressiveness remain bounded by actual implementation and reviewed envelopes, not merely by conceptual permissions.

## Actual R4 contract

The pure build/update APIs retain consented, source-hashed ACTUAL_EXECUTION events with event identity, observation time, context and explicit comparability; duplicate/stale/unproven events are excluded. These are reference data contracts, not authenticated production ingestion. Generalized recency decay and calibrated recovery learning are not implemented. A repeated-association safeguard does not establish a universal observation-count sufficiency rule.

Associations can be reported as advisory evidence. Executable learned selection remains blocked by LEARNED_OPTION_ADMISSIBILITY_CONTRACT until a reusable material contract validates complete prescriptions, dose equivalence and placement. Self-declared sameDose/admissible flags never authorize a prescription. ATHLETE_LEARNING_MODEL_READINESS remains NOT_READY.
