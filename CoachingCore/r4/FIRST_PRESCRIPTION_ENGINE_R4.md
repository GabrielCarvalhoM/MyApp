# First prescription R4

A new eligible athlete does not need imported device or Vilumo history before receiving useful training. Self-reported recent exposure, competence, goals and constraints support bounded establishment. The registry chooses reversible starting options, not guaranteed optimal population doses.

1. Eligibility and scope first; ask if genuinely unknown
2. Use self-report as self-report, not verified observation
3. Choose productive low-demand entry in demonstrated patterns; no perfect product history requirement
4. Compose full requested scope only if every task and window is supported
5. Unknown externally loaded task does not acquire load from generic priors
6. Observe actual completion/effort/technique/function before progression

Collect actual execution, effort, technique/performance, recovery and adherence. These can replace generic priors only within comparable contexts and allowed learning purpose. A full week requires a complete feasible proposal; partial run output cannot count as a complete hybrid week. The final readiness report reflects actual frozen and independent holdout results, not this specification alone.
