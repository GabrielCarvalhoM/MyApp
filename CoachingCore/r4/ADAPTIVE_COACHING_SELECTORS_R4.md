# Adaptive coaching selectors R4

new observation → materiality and data quality → future essential stimuli/horizon → goal and priority → admissible complete options → goal-preserving ordinal selection → smallest sufficient change → future observation.

- NOISY_KEEP: one isolated small mismatch, otherwise compatible → KEEP.
- EARNED_PROGRESSION: comparable consistent easier-than-target response and compatible recovery → one smallest supported familiar progression.
- CONFIRMED_UNDERPERFORMANCE: repeated comparable harder-than-target response → provided familiar lower task demand.
- LOCAL_OPTIONAL: local concern with essential work currently compatible → omit unperformed optional local work.
- SYSTEMIC_SUFFIX: converging systemic response and early-ended hard work → remove remaining hard work; easy exit only if comfortable.
- MISSED_OPTIONAL: confirmed optional omission with feasible core → discard/KEEP remainder, no catchup.
- CONFLICT: actual scheduling conflict → feasible same-dose one-session move protecting primary/key work.
- RETURN: known nonclinical logistics pause → reversible familiar low-demand entry and response review.

Future development is the reason to adapt. A reduction can best serve the goal when preserving current work would create unnecessary cost. KEEP can best serve it when the signal is noise. No extra change is earned merely by calling the system adaptive. Important remaining selectors: arbitrary missed essential move/merge/replan over whole future block; full novel program and all event/taper profiles; unbounded in-session load/pace adjustment.
