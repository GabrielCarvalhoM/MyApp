# Adaptive program coaching — R5

Learning does not itself mutate the plan. The reviewer compares KEEP against a bounded minimum intervention and validates every changed uncompleted session. No in-cycle mutation is justified by priority alone or an isolated noisy response.

Scope: OFFLINE_SYNTHETIC_NODE24_REFERENCE. Candidate implementation; not Product Truth, production, clinical or empirical validation.

## families

- MISSED_OPTIONAL: Discard without debt
- MISSED_ESSENTIAL: Keep next essential horizon or use current complete same-dose configuration; never compress debt
- UNDERPERFORMANCE: Isolated KEEP; recurring comparable mismatch may regress to a known minimum alternative
- OVERPERFORMANCE: Repeated surplus and compatible recovery may earn a single future dose dimension
- LOCAL_FATIGUE: Only affected uncompleted optional work
- SYSTEMIC_FATIGUE: Covered optional reduction or scoped ASK for compatible reduced task
- SCHEDULE_CHANGE: Current feasible Pareto configuration before trade-off
- TRAVEL: As schedule change with explicit next-horizon windows
- DOUBLE_INFEASIBLE: As schedule change; no overlapping windows
- SESSION_MOVED: Revalidate full configuration and future dose
- PROGRESSION_NOT_TOLERATED: Use actual evidence/known lower alternative
- PROGRESSION_TOO_EASY: Earned progression guard
- RETURN: Known nonclinical reason/current demonstrated bounded easy task; otherwise ASK/clinical
- EVENT_NEAR: No new overload; separately bound event configuration
- CONFLICT: Preserve both when possible
- GOAL_CHANGE: New complete validated program input required

## actions

- KEEP
- DISCARD
- MOVE
- REDUCE
- PROGRESS
- REGRESS
- PARTIAL_REPLAN
- ASK
- HOLD
- UNSUPPORTED
- CLINICAL_HUMAN_REQUIRED

## limits

- Substitution and wider block adjustment are represented as dependent alternatives, not broadly implemented positive selectors
- Clinical return is never a deload workaround
- Repeated essential losses need broader trajectory reasoning still open
