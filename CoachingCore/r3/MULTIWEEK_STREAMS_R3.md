# Canonical multiweek streams R3

Three explicit priority profiles × four weeks × seven labelled days =84 evaluations. Familiar request, incompatible current context, nonclinical pause, unknown eligibility, clinical concern, partial completed work and confirmed optional omission are exercised through normalization and the semantic consumer. Each next context is supplied, never physiologically inferred. All invariant assertions run in simulate-r3.mjs. These84 rows are not extra representative cases or empirical athlete trajectories.
