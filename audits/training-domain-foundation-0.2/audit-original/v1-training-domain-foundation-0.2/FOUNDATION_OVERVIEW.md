# V1 Training Domain Foundation — 0.2 review candidate

## Status
**READY WITH FIXES for scoped human domain review; NOT Product/Domain Truth and NOT runtime authority.** Independent technical review/disposition and exact hashes are supplied in the audit bundle. This is a proposed payload foundation, not a complete factual exercise library, approved policy or validated estimator.

This package materializes the training-domain concepts already required by the current Run Intelligence, Strength Intelligence and Sport Intelligence specs. It does not replace G01–G04 human/domain review and does not reclassify the eight domain-open Adaptive Engine cases.

## Four pillars
1. Strength Exercise Ontology
2. Run Session / Workout Ontology
3. Shared Training Demand & Interference Model
4. Concrete Seed Dataset + Scenario Integration

## Core separation
- **Fact**: only source-bound or reconciled observations with provenance and coverage. Names are curated identity; muscle roles/equipment/configuration in these seeds remain unverified taxonomy candidates. Merely being stable metadata does not make a field a verified fact.
- **Domain judgment**: movement pattern, relative demand tendencies, substitution equivalence, session purpose.
- **Derived estimate**: estimated training cost for this prescription and athlete.
- **Policy**: what change to make, when, and why. Policy remains G01–G04 / human-review dependent.

## Non-negotiable model rule
`exercise/session identity != training cost`. The 0.1 unanchored per-identity bands were removed from active seeds; original values remain in the immutable 0.1 audit input.

Strength: `Exercise Metadata × Prescription × Athlete/Context → Estimated Training Cost`

Run: `Run Session Definition × Prescription × Athlete/Context → Estimated Training Cost`

Hybrid: demand overlap plus dose, timing, recovery, priority and response evidence informs SIS InteractionAssessment. These are dependencies, not a multiplication formula. Endpoint, acute/chronic horizon, applicability and uncertainty are explicit; no universal comparator is delivered.

Overlap never implies automatic plan mutation.

## What 0.2 adds, and what it leaves for the actual owners

Preserves 32 strength/17 run IDs and the four pillars. Adds typed conceptual boundaries/cardinalities, explicit configuration/units/unknown/execution/version semantics, a bounded evidence ledger and one shared synthetic fixture file with 14 case prompts, seven strength variations, six strength prescriptions and three run prescriptions. Taper remains a phase template. All dose/target/athlete examples are invented for representability, not advice or accepted sporting outcomes.

The AE consumes refined SessionIntent/SessionDemand/ExposureContribution and SIS InteractionAssessment, never a parallel foundation policy. EstimatedTrainingCost is a training-demand projection; Change Cost describes disruption to a commitment. Catalog presence does not prove adequacy, necessity, minimum effective change or substitution equivalence.
