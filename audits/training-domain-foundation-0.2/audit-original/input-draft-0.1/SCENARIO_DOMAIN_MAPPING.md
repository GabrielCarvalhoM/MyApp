## C1–C6 support
- C1: costs can be projected and reconciled across multiple days without summing planned + observed twice.
- C2: same-day RunPrescription + StrengthPrescription share a timing/interference context.
- C3: alternatives can be compared on preserved intent and changed demand dimensions, enabling Pareto reasoning.
- C4: candidate modifications can explicitly change one axis (micro/volume/move/substitute/replan) and compare cost.
- C5: run archetype and session role carry event/phase/taper context.
- C6: planned autoregulation envelope is represented separately from a new plan mutation.
