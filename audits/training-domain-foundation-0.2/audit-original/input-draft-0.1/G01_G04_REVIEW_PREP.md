# G01–G04 Review Preparation

## G01 — coverage / repertoire / athlete profiles
Now reviewable: which exercises/archetypes exist, equipment coverage, goal tags, movement/session families, and where seed coverage is missing.
Human questions: Is the repertoire sufficient for V1 runner/strength profiles? Which variations are inappropriate for novice/intermediate populations? Which running-specific strength items are missing?

## G02 — dose / adequacy / progression / substitution / interference
Now reviewable: the exact variables that a policy may use and candidate shared-demand dimensions.
Human questions: Which candidate demand tags are defensible? What substitution criteria preserve stimulus? What evidence is enough for Level 1 vs Level 2 vs MOVE? Which session-role protections should exist?
Still open: exact dose rules, positive MEC witnesses, approved interference policy.

## G03 — adherence / comparability
Now reviewable: planned-vs-completed structures for sets/reps/load/RIR and run blocks/steps; intensity-reference versioning.
Human questions: What deviations are comparable vs not comparable? When is partial completion sufficient to assess progression?

## G04 — restrictions / return
Now reviewable: where restrictions must gate exercise/session eligibility and how return scenarios reference current context.
Requires qualified clinical input where claims become clinical/injury-return decisions. This foundation does not authorize diagnosis or return-to-sport clearance.
