# R4 correction root causes

Independent Quality and SSCTR found material defects after initial raw coverage improved. The first holdout and failed probe evidence remain preserved; a passing author test suite did not substitute for independent review.

1. Context propagation was incomplete. Candidate generators saw task facts but omitted supplied availability, equipment and environment. The reusable correction carries these constraints into candidate assessment and checks total run/strength planning budget before a full-task positive.
2. Positive-word substring matching accepted negated response, technique and ordinary function. Contradictory/adverse context must take precedence over positive words; task/environment comparability cannot be inferred from the word “compatible” alone.
3. Training roles were collapsed. Selecting the last reported run as an easy anchor could use a long run, inflate weekly volume/frequency and erase strength work. Complete goal/priority/family-specific patterns are required; incomplete configuration is an explicit gap or question.
4. Generic descriptions were mistaken for executable alternatives. A symbolic schedule name does not establish complete same-dose prescriptions or actual windows; a load number does not establish equipment or per-hand/total basis.
5. Completed-work preservation alone did not prove a meaningful prospective intervention. An optional omission requires an actual affected unperformed remainder. In-session early termination should use actual completed dose and current response, not one exact narrative phrase.
6. Goal interpretation scanned secondary maintenance text as if it were the primary goal. Primary, secondary, phase and horizon must retain distinct roles in candidate preference.

The fix is shared validation and explicit material contracts, with exact independent reproductions and regression tests. It is not a scientific requirement for a paper approving every concrete output. Operational scheduling estimates remain assumptions with actual elapsed-time/technique safeguards. Reviewers re-run their own adverse probes on final source hashes; no failed initial evidence is overwritten as a historical pass.
