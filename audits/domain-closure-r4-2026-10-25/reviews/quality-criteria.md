# Independent coaching decision criteria — R4

This criterion set was recorded after holdout sealing and before R4 runtime inspection. Runtime self labels and selected candidate IDs do not define the independent outcome. Apply the same criteria to the frozen40 and holdout24.

1. **Scientific admissibility.** The actual proposed task/action must remain inside a current independently reviewed envelope, including population, conditions, usable anchors, complete-task scope and scientific uncertainty. A hash binding proves which artifact was reviewed; it does not prove that the selected task met its conditions.
2. **Goal and phase.** The rationale must use supplied primary/secondary goals, priority, phase and horizon when they can change selection. Bounded request intent can support a narrow action when detailed goals are absent, but it cannot establish full goal-optimal coaching or invent a training phase. A trace that lists goals without using them does not prove alignment.
3. **Executable scope.** Judge the complete requested output. A productive subtask is not a completed hybrid week. A symbolic arrangement is not a feasible executable schedule without window, dose and overlap evidence. Concrete run duration includes preparation, recovery and cooldown. Strength tasks retain configuration and load units.
4. **Alternatives.** Identify supplied or clearly available admissible alternatives. If an alternative is materially better for the athlete's stated objective at no greater unsupported risk/cost, selecting the dominated choice is COACHING_SUBOPTIMAL even if safe. Do not reward invented candidate lists that fail to represent the real trade-off.
5. **Minimum effective change.** There must be a material reason for changing a plan. Preserve unaffected essential work, completed actual work and the future key stimulus. Do not compensate missed optional load, change several dimensions without need, or reduce productive exposure merely because a generic prior is smaller.
6. **Athlete evidence.** Use actual current capacity and comparable individual response where available. Distinguish self-report, measured observation and population priors. Repeated IDs cannot create independent evidence. One noisy/confounded event cannot produce a hard rule. No universal sample threshold or causal assertion follows from an observational pattern.
7. **ASK / KEEP / HOLD quality.** Correct narrow ASK, KEEP or HOLD may be COACHING_BEST_SUPPORTED but contributes zero positive prescription coverage. Ask only for a fact whose answer can change the decision and which is not already available in history. Unsupported policy logic is reported as a domain gap rather than disguised as an athlete question.
8. **Uncertainty and review.** Explain the material accepted trade-off and what future execution, effort, recovery or context would retain/refute the choice. No exact physiological prediction or universal optimality claim is earned by these synthetic cases.
9. **Safety/audit invariants.** Explicit clinical concern routes outside coaching; unknown eligibility stays unknown. Canonical/source hashes, synthetic-only contract, independent review revocation, source facts and shadow state must be enforced. Completed work and official/applied plan state remain immutable.

Classification uses the first material limitation rather than averaging criteria:

| Class | Meaning |
| --- | --- |
| COACHING_BEST_SUPPORTED | Current applicable review and sufficient facts support this complete action; alternatives are coherently compared and no materially better admissible option is ignored. Includes legitimate narrow ASK/KEEP/HOLD without adding a positive numerator. |
| COACHING_ACCEPTABLE_ALTERNATIVE | Action is defensible and useful, but missing meaningful goal/phase/horizon detail, comparison or feasibility prevents a best-supported claim; no demonstrated material domination. |
| COACHING_SUBOPTIMAL | A better admissible option is present or a larger-than-needed/disruptive choice harms the stated objective without justification. |
| INSUFFICIENT_INFORMATION | Material live/establishment/agency facts are missing and the actual decision cannot competently resolve them; a correct targeted ASK can instead be best-supported. |
| UNSUPPORTED | Required scientific/runtime capability, complete-task feasibility, binding or boundary evidence is absent or violated. A genuine correctly disclosed gap still remains unsupported coverage. |
| CLINICAL_OUT_OF_SCOPE | Clinical or otherwise out-of-scope context correctly excludes autonomous coaching. |

No arbitrary aggregate pass percentage is used. A material unsafe or misleading supported-output claim blocks affected readiness regardless of total successful cases. Retained unsupported normal situations restrict broad V1 readiness without invalidating correctly supported narrow capabilities.
