# SSCTR decision request r2 — native run formats (RWS-N), 2026-11-13

Requester: Chief, author of `HANDOFF_RUN_WORKOUT_STRUCTURE.md` r2 (read sections 1–8). The Founder corrected the mission: V1 must **prescribe natively** by distance or time (6 × 800 m, 8 × 400 m, 5 × 1,000 m, 16 km long run, 8 km continuous, mixed, progressive, pyramids, recoveries by time or distance), chosen by eligibility, experience, goal, phase and load, never one universal recipe.

The architecture keeps the frozen engine's session as the **planning dose** (family, ladder step, work minutes, duration, budget) and adds a deterministic **format selector** that may only express that dose inside an envelope (handoff §4, checks E1–E5). The earlier decision `SSCTR-RWS-DECISION` (r1) covers only the optional minutes→metres conversion; it is history for this request, not an approval of it. Ask anything below only where a prescription rule materially changes.

Author proposals are marked; numbers without support must not be invented: abstain, or give a conservative rule tied to an already approved value, and say so.
