# Run Prescription Engine Foundation

**ACF-1.0.0-r1 · 23/10/2026 · CANDIDATE / NON-AUTHORITATIVE.** Owner: prescription author fallback instance. This author is not the SSCTR judge. No production/runtime prescription, Product Truth promotion, clinical clearance or real athlete validation follows from this document.

This candidate extends the retained domain semantics of RIL-1.1-r1 under SIS/AEC/AEOS. The consumer is the future Run Prescriber and integrated Hybrid Planner: the contract turns intent into finite ordered executable steps and evaluates a concrete change against that baseline. [RUN_SESSION_RECIPES.json](RUN_SESSION_RECIPES.json) contains 16 finite candidate recipes, not a catalog generated by an unconstrained LLM. The independent scientific disposition lives in SCIENTIFIC_DECISION_REGISTRY and review records; author status is not approval.

## Inputs and decision boundary

Resolve athlete/model revision, modality-specific experience, goal/event and accepted priority, phase, actual recent exposure and comparable task capacity, availability, surface/environment/equipment, eligibility, recovery/readiness, prior response and accepted authority/envelope. Running novice status is independent of strength expertise. Rich sensors do not override task eligibility or incomplete history. An explicitly synthetic nonclinical premise is not an assessment of a real person.

Each missing field has a purpose: ask only when it can change candidate selection, dose, interpretation or authority. Missing physiological calibration cannot be filled with age-predicted HRmax, group pace, a percentage of an unvalidated maximum or a generic threshold RPE. Known comfortable task-anchored easy movement may remain eligible under its own reviewed family; eligibility itself cannot be inferred from silence. Unknown interruption reason asks first. Clinical injury/illness return, persistent pain, pathology, new functional limitation and clearance stay CLINICAL_HUMAN_REQUIRED.

## Implementable request, response and units

Request = athlete_state_ref + goal/phase/priority refs + reconciled history refs + eligibility ref + readiness ref + response_model_ref + availability/context + candidate recipe revisions + authority/envelope ref. Response = PRESCRIPTION_PROPOSAL or ASK / HOLD / OUT_OF_SCOPE; it is never a direct plan write.

A PRESCRIPTION_PROPOSAL carries recipe/version, intent, essential/optional work, ordered steps, primary target method and reference, all bounds/units, demand interpretation, evidence/decision refs, preserved/lost stimulus, rationale, confidence/unknowns, accepted adaptation envelope and next check. Every target binding must resolve to the specific athlete or authorized verbal task anchor before execution. Templates may retain references; the emitted workout may not retain unresolved placeholders.

Each SINGLE step has TIME in seconds or DISTANCE in metres, role, completion, target and advance rule. Each REPEAT has an integer **total** iteration count, work, between-iteration recovery and explicit recovery_after_final. In this catalog recovery_after_final=false. Cooldown is separate. The final recovery is not silently duplicated. A future distance-controlled recipe must supply metres and cannot infer metres from an estimated time or round a target-derived distance into a completion requirement.

Pace uses seconds per kilometre; lower values are faster, so a range is sorted numerically but interpreted with inverse speed meaning. HR is beats per minute with a valid method-specific reference. Power is watts with device/protocol identity. RPE has scale, anchors, assessment moment and task applicability. One primary control method is chosen; secondary signals have explicit cross-check precedence. No average of conflicting pace/HR/RPE is allowed. Every example target is synthetic and can be rebound only through athlete-specific calibration. Labels such as VO2-style and threshold-intent are not measurements.

The recipe numeric_provenance enumerates each numeric leaf: SYNTHETIC_DESIGN_POINT versus DERIVED_ARITHMETIC. Exact fixture sets, minutes, rests, paces and increments are **DECIDED operational design candidates**, never represented as scientific optima, population safety cutoffs or individual predictions. A positive execution witness still requires independent review for the exact bounded use. All actual/history values remain OBSERVED with source/revision elsewhere; a JSON example is not observation.

## Construction algorithm

1. Read the current accepted plan first. If adequate, no new theoretical improvement authorizes replacement.
2. Derive the intended goal/family and essential stimulus from the accepted block, rather than adding hard work to satisfy a category.
3. Filter by eligibility, phase, task competence, comparable capacity/tolerance and context. Select familiar finite recipes before novel configurations.
4. Bind primary target/calibration, select a finite already tolerated or independently reviewed variant, and expand all steps.
5. Compute duration, work duration, recovery duration and estimated versus prescribed distance separately. Include warmup/cooldown in availability.
6. Validate total week and next relevant session across Run and Strength, protected versus flexible stimuli, cumulative local demand and previously accepted commitments.
7. Return proposal plus reason, exact evidence limits, authority level and next check. Only Orchestrator may publish one final plan under AEC.

An empty eligible set is an explicit ASK/HOLD with smallest missing input or recipe gap. It is not permission to invent a session. This is an executable selection architecture, not an assertion every catalog row has received prescriptive approval.

## Concrete expansion and fidelity

RUN-CRUISE3X6 expands to 10 min easy warmup; 6 min at the synthetic athlete's own 330–340 s/km threshold-intent reference; 2 min easy jog; 6 min work; 2 min easy jog; 6 min work; 8 min easy cooldown. Total **40 min**, intended work **18 min**. The example's pace and method are synthetic assumptions; no paper proves these numbers for a real athlete. A valid physiological threshold interpretation depends on the specific actual assessment and applicability; RPE alone cannot create it. A controlled-hard subjective alternative must carry its own construct/family, not inherit threshold validation by wording.

The intended 3 x 8 min example requested by Founder is represented by the same repeat schema but is **not inferred as progression approval from 3 x 6**. To instantiate it, record comparable athlete exposure/tolerance or a separate bounded approved establishment method, explicit 24 min work and 2 between-bout recoveries, full warmup/cooldown/time budget, hybrid implications and independent disposition. Exact numbers are finite policy choices with provenance. Refusing an unsupported physiological claim does not require withholding independently eligible familiar easy or strength work.

RUN-NOVICE-WALKRUN20 and RUN-RETURN20 are distinct despite identical step forms. Both show 5 x 1 min comfortable jog, 1 min walking only between bouts, 5 min walking beginning and 6 min end: **20 min total**. Novice eligibility does not infer running capacity from lifting; return eligibility requires a known nonclinical/logistical reason and current familiar task context. The candidate first exposure does not certify a whole return progression or zero-history population coverage. Those exact dose/trajectory approvals remain open pending sufficient review.

## Progression, adaptation and observation

Separate planned progression, observation-driven learning and reactive adaptation. Between-cycle is the normal opportunity for earned progression. Repeated comparable supported response can favor a named next duration/repetition variant; retain pace/rest/frequency unless their separate axis is justified. No universal 10% rule, intensity distribution, long-run fraction or automatic deload week exists. If the comparator is not adequate, report why keeping the current dose or changing a smaller parameter is insufficient before proposing a larger change.

Overperformance updates actual facts and candidate future progression. It does not add repetitions today or rewrite next week after one quick run. Underperformance first checks actual target/revision, comparison conditions, sensor/manual quality, prescribed reductions, rest and external context. It does not prove strength interference, deconditioning or systemic fatigue. Actual adherence is to the accepted executed version; shortening already authorized by the plan is not failure of the old dose. No missed-session debt or catch-up intensity is created.

In-session actions preserve the completed prefix. A preaccepted named remainder reduction can be used only if it restores adequate intent and current authority permits it. Otherwise pause and propose/confirm the actual remaining change; an unanswered prompt is not approval. Unexpected symptom/clinical concern does not select a generic easier run. Stop/clinical routing is distinct from a nonclinical ASK and from optional early completion.

## Hybrid demand and recovery

Report total/fast/prolonged exposure, surface/gradient, novelty and local/systemic uncertainty. These are context interpretations of the same planned/actual facts, not new activities to sum. RUN-STRIDE6X15 attached to easy must not duplicate the common warmup or count one completed activity twice. Lower-before-run and run-before-strength are candidate relations evaluated against actual individual history and task outcomes; no blanket 24/48-hour rule or arbitrary spacing multiplier is created. Chronic concurrent evidence cannot diagnose tomorrow's readiness, and acute performance changes cannot establish chronic interference. [Concurrent training synthesis](https://link.springer.com/article/10.1007/s40279-021-01587-7), [acute runner review](https://link.springer.com/article/10.1186/s40798-022-00497-w).

## Taper, race week and limits

Taper reduces/redistributes demand for a defined event while considering retained familiar intensity, athlete history and strength goal. Group taper evidence supports the concept with limits; it does not prescribe the exact combined hybrid taper or guarantee a response. RUN-TAPER25 and RUN-RACEWEEK20 are deliberately concrete candidate witnesses with smaller familiar touches, not an individualized optimal taper. No pre-taper overload is added from a meta-analysis recommendation without task-specific evidence. Race date, distance, accepted realistic target, availability/travel and both modalities must be explicit. [Taper systematic review](https://pmc.ncbi.nlm.nih.gov/articles/PMC10171681/).

## Negative paths and review contract

| Missing / conflicting condition | Result |
|---|---|
| Unknown restriction/eligibility or pause reason | C / ASK; dependent dose held until decision-changing answer |
| Uncalibrated threshold label | Ask for valid reference or select independently eligible nonthreshold family; no fabricated pace/HR |
| Novel hills/fast work without task tolerance | Hold that family; retain only eligible alternative with changed stimulus explicit |
| Inadequate time after warmup/recovery | Named reduced variant or reviewed substitution; never delete rest/warmup silently |
| Clinical return/persistent pain/new functional limit | E / CLINICAL_HUMAN_REQUIRED; no coaching dose as workaround |
| No sufficient evidence for exact proposed progression | D for dependent advance; familiar adequate plan may remain unchanged if valid |

Every material claim/recipe requires SSCTR review from a separate instance, exact version/hash, applicable sources/limits, and future human queue entry if approved prescriptively. Source presence does not imply exact dose approval. Author self-checks only establish structural consistency. Broad novice establishment, complete return trajectory, specialized event peaks, different terrain/equipment and numerical physiological tolerances remain bounded gaps rather than inferred coverage.
